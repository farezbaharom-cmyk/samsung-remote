# Remote TV Samsung

Remote web untuk Smart TV Samsung (Tizen, model 2016 ke atas) melalui Wi-Fi.

Buka: https://farezbaharom-cmyk.github.io/samsung-remote/

1. Telefon dan TV mesti guna Wi-Fi yang sama.
2. Isi IP TV (Tetapan → Umum → Rangkaian → Status Rangkaian → Tetapan IP) dan tekan Sambung.
3. Kali pertama, tekan pautan sijil yang muncul, terima amaran, kembali dan tekan Sambung semula.
4. Pilih Benarkan pada skrin TV.
